## Changelog
Part 2 changes implemented:
- Fixed Navigation Menu overlapping, restructured 'nav-container' and 'nav-menu' inside mobile media queries using vertical flex orientation, standardized spacing, and dedicated touch boundaries to eliminate menu overlaps when resizing
